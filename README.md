# Калькулятор бюджета

Работа по модульному тестированию веб-приложений. Проект сделан на .NET 8, тесты написаны на xUnit.

## Запуск тестов

Открыть папку проекта в VS Code и выполнить:

```powershell
dotnet test BudgetTests.sln
```

## Что проверяют тесты

- Расчёт без страховки: 100 × 5 = 500.
- Расчёт со страховкой 5%: 100 × 5 = 525.
- Отрицательное количество дней возвращает ошибку 400.
- При нулевой стоимости результат равен 0.
- Стоимость 100.50 за 3 дня считается как 301.50.

В расчёте страховки была ошибка: сумма умножалась на 5. Ошибка исправлена, теперь к сумме прибавляется 5% с помощью `total *= 1.05m;`.

## Результат

Все 5 тестов прошли успешно. Метод `Calculate` покрыт тестами на 100% по строкам и веткам.
