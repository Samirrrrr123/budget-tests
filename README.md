# Калькулятор бюджета

Учебная работа по модульному тестированию веб-приложений. Калькулятор считает стоимость по количеству дней и добавляет 5% при включённой страховке.

Проект написан на C# и .NET 8. В `BudgetApi` находятся модель и контроллер, в `BudgetApi.Tests` — пять тестов xUnit. Тестовый проект подключён к основному через ссылку на проект.

## Запуск

Нужен .NET 8 SDK. В терминале из папки с `BudgetTests.sln`:

```powershell
dotnet test BudgetTests.sln
```

В VS Code можно открыть эту папку и выполнить команду во встроенном терминале. В Visual Studio — открыть `BudgetTests.sln`, затем «Тест» → «Обозреватель тестов» → «Запустить все тесты».

Для первой загрузки пакетов нужен интернет. Запускать веб-сервер отдельно не требуется: тесты напрямую вызывают метод `Calculate`.

## Исправление страховки

В исходном коде сумма умножалась на 5. Тест со страховкой падал: ожидалось 525, получалось 2500. Строка `total *= 5;` заменена на `total *= 1.05m;`, чтобы к сумме прибавлялось 5%.
